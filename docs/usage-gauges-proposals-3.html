Pilules remplies + anneaux : choisir le marqueur de progression

La config retenue : pilules remplies à la place des barres (cellule du header desktop et popover de détail), anneaux là où il y a déjà des anneaux (bandeau comptes, header mobile). Reste à choisir le marqueur de progression, c'est-à-dire comment on montre la part de la fenêtre déjà écoulée, et on peut en prendre un différent pour les pilules et pour les anneaux.

L'aperçu juste en dessous montre toutes les surfaces avec ta combinaison. Change-la avec les deux menus, ou avec le bouton « Mettre dans l'aperçu » de chaque carte. Pour répondre : deux IDs, par exemple « PL1 + RG3 ».

AMarqueurs pour les pilules

Une pilule est plus haute qu'une barre (10 px dans le header, 18 dans le popover) et porte du texte : le marqueur ne doit pas cacher le libellé ni le pourcentage. D'où beaucoup de marqueurs sur le bord ou sous la pilule.

BMarqueurs pour les anneaux

Les anneaux du bandeau (22 px) et du mobile (28 px). Ici le marqueur peut vivre sur le trait, à l'extérieur, ou à l'intérieur du cercle.

Mes recommandations

Ce que ça touche dans le code

À corriger au passage : en thème clair, la piste des barres du popover (--bg-inset) a exactement la couleur du popover : la partie vide est invisible aujourd'hui déjà. Les pilules du popover utilisent ici une teinte du texte (9 %), visible dans les cinq thèmes.

Pilules : la cellule runtime (UsageMeter, mode runtime) et la Bar du popover deviennent une pilule : un fond (piste + remplissage teinté par la sévérité), le libellé et le pourcentage dedans, et le marqueur en SVG par-dessus (comme PaceMark aujourd'hui, pour garder la même taille à tous les zooms). Anneaux : seul le marqueur de Ring change. Aucune donnée nouvelle : tout vient de utilization, resetsAt et paceFraction().
